# Preview capture renderer

`html2canvas-pro-2.4.5.min.js` is the unmodified browser bundle from
[html2canvas-pro 2.4.5](https://www.npmjs.com/package/html2canvas-pro/v/2.4.5),
maintained at [yorickshan/html2canvas-pro](https://github.com/yorickshan/html2canvas-pro).
Its MIT license is in `html2canvas-pro-LICENSE`.

The backend embeds this file so capture works without a CDN. This version supports
modern CSS colors such as `color()`, `lab()` and `oklch()`, including computed styles
returned by WebKit. Keep the browser bundle pinned and update its versioned asset
URL, license, and capture tests together.
