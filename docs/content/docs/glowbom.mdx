Glowbom is a sketch-to-software tool. Start with something you can show or
explain, try a working prototype, and continue building with tools you choose.

## Start with a sketch

Open [Glowbom Web](https://glowbom.com/draw/), draw your idea, and describe what
should happen. Generate a prototype and test its behavior before deciding what
to change next.

A generated result is a starting point. Review its behavior, code, and platform
requirements before publishing it.

## Continue with local tools

[Glowbom Desktop](./desktop) brings coding agents, Chat, Draw, Studio, and the
Project Book together in a Mac app. It is available through
[early-access signup](https://glowbom.com/desktop).

[Glowbom OSS](./glowbom-oss) lets you load local project files and work with coding
agents through OpenCode, Codex, Cursor, Claude Code, or a configured ACP
connection. [Agents](./connect-ai) explains how to install an agent, sign in,
and choose a model. You can use a Glowbom export, the bundled starter, or
another project structure. OSS works independently of Desktop, without a Glowbom
account or early-access signup.

The starter contains Apple, Android, and web folders. Each target still needs
its own build tools and testing. Generating code does not automatically produce
a tested app for every platform.

## Keep what the project means

The [Project Book](./project-book) keeps saved work, stories, drawings, and source
details beside the code. Read or correct an entry in Glowbom Desktop to
understand what changed before deciding what to build next.

## Choose your environment

- **Web:** capture an idea and try a prototype.
- **Desktop:** the full Mac app is available through early access.
  [Sign up at glowbom.com/desktop](https://glowbom.com/desktop), then follow the [Desktop guide](./desktop).

The Desktop guide also introduces the separately installed
[companion apps](./companion) for iPhone, iPad, and Vision Pro, optional
[Glowbom Live](./glowbom-live) for Buzz channels, and the independent OSS path.
Desktop and Live are closed-source apps that use the open backend.

See the [Quickstart](./quickstart) for the first steps.
