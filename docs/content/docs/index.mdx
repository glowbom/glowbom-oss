Glowbom starts with a sketch, a photo, or a few words. Build a prototype, try it,
and keep improving it with local tools and coding agents.

Our direction is simple: building software should feel like writing a book.
A [Project Book](./project-book) keeps the project's intent, decisions, and history
beside the code so people and agents can understand where to go next.

## Choose where to start

| Experience | What it is | Start here |
| --- | --- | --- |
| Glowbom Web | Sketch and try a prototype in your browser. | [Open the canvas](https://glowbom.com/draw/) |
| Glowbom OSS | The open backend, CLI, and Agent + Buzz browser workflow. | [Install and run](./glowbom-oss) |
| Glowbom Desktop | The separate full interface, available as a Mac early-access app. | [Desktop status](./desktop) |
| iOS and Vision Pro companion | A preview for using shared Desktop projects from iPhone, iPad, or Vision Pro. Requires a matching app build. | [Pair with Desktop](./companion) |

## Your first project

Follow the [Quickstart](./quickstart) to sketch on the web and continue with local
files. You can also start directly in Glowbom OSS using the bundled project
without a Glowbom account.

## What stays yours

Glowbom OSS works with files on your computer. You can open and edit those files
with other tools. When you choose a cloud model, its provider receives the inputs
needed for that request; running the interface locally does not make every AI
request offline.
