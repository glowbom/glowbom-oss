## 1. Open the canvas

Go directly to [glowbom.com/draw](https://glowbom.com/draw/). This is the builder;
[glowbom.com](https://glowbom.com) is the main product website.

## 2. Sketch and describe

Draw the main parts of your idea. Add a short description of what someone should
be able to do. Start with one useful interaction rather than an entire product.

## 3. Build and try it

Use the builder's generation controls to create a prototype. Try the result and
note what works, what is missing, and what you want to change.

## 4. Continue with local files

Use the export or download options available in the builder to save your project.
Keep the project folder and its assets together. Export options can differ by
platform and current product version.

To continue in the open-source browser workspace, follow the
[Glowbom OSS setup](./glowbom-oss). Load your saved project folder, choose a
coding agent and model, and describe the next change. The
[Agents guide](./connect-ai) covers agent installation and sign-in.
Review the results before keeping them.

For the full Mac app, [sign up for Glowbom Desktop early access](https://glowbom.com/desktop).
[Desktop](./desktop) is a separate closed-source app with Chat, Draw, Studio,
coding agents, and the Project Book reader. It uses the open Glowbom backend.

## Start locally instead

You do not need a website export or a Glowbom account to use the bundled starter.
After cloning the OSS repository, copy its `project/` folder to a separate working
folder and load that copy in the interface. The [OSS guide](./glowbom-oss#start-with-a-project)
explains the contents.

## Optional Glowbom Live

The Glowbom OSS browser workspace handles coding and Buzz channel connections.
[Glowbom Live](./glowbom-live) is a separate closed-source app that shows your
Buzz channel in a 3D office. Follow its guide for GitHub downloads and setup.
You can use OSS without Live.

## Keep a record

Write down the original idea and the decisions you make alongside the project.
The [Project Book](./project-book) keeps portable records through the open
backend. Use the full Desktop reader to view and edit them, or work with the
files and APIs from your own tools. Keep the Book files with the project.

If you have a matching Desktop and companion build, follow the
[iOS and Vision Pro pairing guide](./companion) to continue from another device.
