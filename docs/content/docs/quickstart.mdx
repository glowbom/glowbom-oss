## 1. Open the canvas

Go directly to [glowbom.com/draw](https://glowbom.com/draw/). This is the builder;
[glowbom.com](https://glowbom.com) is the main product website.

## 2. Sketch and describe

Draw the main parts of your idea. Add a short description of what someone should
be able to do. Start with one useful interaction rather than an entire product.

## 3. Build and try it

Use the builder's generation controls to create a prototype. Try the result and
note what works, what is missing, and what you want to change.

## 4. Continue with local files

Use the export or download options available in the builder to save your project.
Keep the project folder and its assets together. Export options can differ by
platform and current product version.

To continue on your computer, follow the [Glowbom OSS setup](./glowbom-oss).
Open the local interface, load your saved project folder, choose an available
model, and describe the next change. Review the results before keeping them.

## Start locally instead

You do not need a website export or a Glowbom account to use the bundled starter.
After cloning the OSS repository, copy its `project/` folder to a separate working
folder and load that copy in the interface. The [OSS guide](./glowbom-oss#start-with-a-project)
explains the contents.

## Keep a record

Write down the original idea and the decisions you make alongside the project.
The [Project Book](./project-book) describes the format we are developing to keep
that context readable for both people and agents.

The [desktop app](./desktop) is on the waitlist; the local browser and terminal
workflow is available now.
