Glowbom Desktop brings Chat, Draw, Studio, coding agents, and the
[Project Book](./project-book) together in a Mac app. Continue a local project,
preview the result, and keep its saved history alongside the code.

Desktop is a separate closed-source app that uses the open Glowbom backend.
Use this guide to find AI setup, project records, and the related apps.

## Join early access

**[Sign up for Glowbom Desktop early access](https://glowbom.com/desktop).**

Desktop is available for Mac through early access. Windows and Linux Desktop
apps have not been released.

## Desktop guides

| Guide | What you can do |
| --- | --- |
| [Agents](./connect-ai) | Install and sign in to coding agents, connect model providers, or find the local AI setup guide. |
| [Project Book](./project-book) | Read the project's saved work, decisions, and history alongside its code. |
| [Companion apps](./companion) | Pair an iPhone, iPad, or Vision Pro with Desktop to use shared projects. |
| [Glowbom Live](./glowbom-live) | See people and agents from your Buzz channel in an optional 3D office. |
| [Glowbom OSS](./glowbom-oss) | Use the open-source backend, CLI, and coding workspace independently of the Mac app. |
| [Glowbom CLI](./cli) | Prepare starter projects, sign in to your account, and export saved work from the command line. |

The companion apps and Glowbom Live are separate installs. Companion apps connect
to a running Desktop on the same local network and require matching builds.
Glowbom Live is a separate closed-source app; its guide covers the GitHub downloads
and connecting it to Desktop or OSS.

## The independent open-source path

[Glowbom OSS](./glowbom-oss) works without a Desktop installation, Glowbom account,
or early-access signup. It provides the shared open backend and its own browser
workspace for coding and Buzz connections. Desktop's full interface and native
app remain closed-source.

Run OSS on macOS or Linux, or use WSL on Windows. You can work with your own
project or the bundled starter template. Follow the OSS guide for installation
and agent setup.

## Internet and model access

Local project files do not mean every model runs offline. Cloud providers need
an internet connection and their own account or credentials. Local models depend
on your provider setup and hardware.
