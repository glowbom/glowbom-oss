Glowbom Desktop is being developed for **macOS, Windows, and Linux**. The goal is
to bring the open Glowbom workflow into a desktop app, so you can continue a
project with local files, tools, and coding agents.

## Current availability

[Glowbom Live](https://glowbom.com/desktop/#live) is available now as a preview.
It shows people and agents from a Buzz channel as characters in a virtual
office. You still need Glowbom OSS 4.1.0 or later running locally, with a Buzz
channel connected.

Glowbom Desktop, the broader local app for continuing a Glowbom project, is
still on the waitlist at [glowbom.com/desktop](https://glowbom.com/desktop/).
This guide does not provide a Desktop installer.

## Continue the same project

The intended workflow is to begin with a sketch or prototype, open the project
on your desktop, and keep improving it while preserving what you meant in its
[Project Book](./project-book). Platform installers and supported handoff steps
will be documented when released.

## Build locally today

[Glowbom OSS](./glowbom-oss) is available now. It runs a local backend and browser
interface on macOS and Linux; on Windows, use WSL for the documented setup.
You can work with your own project or the bundled starter template.

## Internet and model access

Local project files do not mean every model runs offline. Cloud providers need
an internet connection and their own account or credentials. Local models depend
on your provider setup and hardware. We do not promise fully offline operation
for the upcoming desktop release.
